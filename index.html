UNIDAD 1

Conceptos de Modelamiento y Simulación

Propósito: comprender los fundamentos necesarios para representar un sistema y planear un estudio de simulación.

1. Sistema y pensamiento sistémico

Un sistema es un conjunto de elementos relacionados que interactúan para alcanzar un propósito. En Ingeniería Industrial interesa no solo estudiar cada elemento, sino comprender cómo una modificación en una parte puede afectar el comportamiento global.

Todo estudio necesita una frontera, que determina qué se incluye; un entorno, que reúne factores externos; entradas, actividades de transformación y salidas.

📦 Entidades

Piezas, clientes, pedidos.

⚙️ Recursos

Máquinas, operarios, vehículos.

🏷️ Atributos

Prioridad, tipo, lote.

📊 Variables de estado

Inventario, cola, recursos ocupados.

🔧 Actividades

Proceso, inspección, transporte.

⚡ Eventos

Llegada, salida, falla, reparación.

Ejemplo: centro de distribución

Los pedidos son entidades; operarios y montacargas son recursos; la prioridad del pedido es atributo; pedidos esperando es variable de estado; alistamiento es actividad y llegada de pedido es evento.

2. Modelo y modelamiento

Un modelo es una representación simplificada de la realidad creada para un propósito. El modelamiento decide qué representar, qué relaciones incluir, qué supuestos aceptar y qué nivel de detalle utilizar. Puede ser físico, conceptual, matemático o computacional.

Principio: agregar detalle no garantiza un modelo mejor. Debe incorporarse aquello que ayuda a responder el objetivo.
Ejercicio resuelto

Para estudiar si una empacadora atiende la producción diaria son relevantes jornada, tiempo de empaque, demanda, número de empacadoras y paradas significativas. El color del equipo no es relevante para ese objetivo.

3. ¿Qué es simulación?

La simulación es la experimentación con un modelo para estudiar el comportamiento de un sistema bajo diferentes condiciones. Permite plantear “¿qué pasaría si...?” antes de realizar cambios reales.

Ejemplo: antes de comprar una segunda máquina, una empresa puede comparar el escenario actual con otro de capacidad adicional observando producción, utilización, esperas y restricciones.

4. Tipos de simulación

Discreta

El estado cambia con eventos.

Continua

Las variables evolucionan continuamente.

Determinística

Mismas entradas, mismos resultados.

Estocástica

Incluye variabilidad aleatoria.

Estática

No representa evolución temporal explícita.

Dinámica

Representa evolución en el tiempo.

Actividad de clasificación

Línea con llegadas variables, colas y máquinas → discreta, dinámica y normalmente estocástica. Nivel de tanque → continua y dinámica. Cálculo fijo de capacidad → determinístico simplificado.

5. Ventajas y limitaciones

Ventajas: experimentar sin interrumpir el sistema real; comparar alternativas; estudiar interacciones; identificar cuellos de botella; representar variabilidad; evaluar riesgos.

Limitaciones: requiere datos y conocimiento; depende de supuestos; puede ser costosa en tiempo; y no encuentra automáticamente la decisión óptima.

Regla: un resultado preciso no compensa un modelo conceptualmente equivocado.

Verificación vs. validación

Verificar pregunta si el modelo fue construido según la lógica definida. Validar evalúa si representa adecuadamente el sistema para el propósito.

8. Indicadores productivos

Capacidad: máximo procesable. Throughput: unidades que salen. Utilización: proporción de capacidad usada. Cuello de botella: recurso que limita el flujo. Tiempo de espera: demora antes del proceso. WIP: trabajo en proceso. Demanda no atendida: parte no cubierta.

Capacidad aproximada = (tiempo disponible ÷ tiempo por unidad) × recursos paralelos
Ejemplo resuelto

480 min y 6 min/u → 80 u/día. Si baja a 4 min/u → 120 u/día.

UNIDAD 2

🎲 Generación de números aleatorios

Propósito: comprender cómo se representa la variabilidad y cómo una secuencia U(0,1) puede transformarse en variables de un sistema.

1. Variabilidad e incertidumbre

Tiempos de proceso, llegadas, demanda, fallas y reparaciones pueden variar. Un modelo determinístico usa entradas fijas; uno estocástico incorpora variables aleatorias.

2. Números pseudoaleatorios

Son valores producidos por algoritmos determinísticos diseñados para presentar propiedades estadísticas apropiadas. Una base habitual es una secuencia aproximadamente uniforme en 0≤U<1.

3. Propiedades deseables

Uniformidad

Cubrir adecuadamente el intervalo.

Independencia

Evitar dependencias sistemáticas.

Periodo

No repetirse demasiado pronto.

Reproducibilidad

Permitir repetir experimentos.

4. Semilla

La semilla inicializa el estado del generador. Con el mismo algoritmo y estado inicial puede reproducirse una secuencia, útil para depuración y comparaciones.

5. Generador congruencial lineal

Xₙ₊₁ = (aXₙ + c) mod m   ;   Uₙ = Xₙ/m

X₀ es semilla; a multiplicador; c incremento; m módulo. Los parámetros influyen en el periodo y calidad.

Ejemplo manual

X₀=3, a=5, c=1, m=16. X₁=0 → U₁=0. Luego X₂=1 → U₂=.0625.

6. Pruebas estadísticas

No basta con que una secuencia “parezca aleatoria”. Se evalúan propiedades como uniformidad e independencia. Pueden estudiarse pruebas de frecuencia, medias, chi-cuadrado, Kolmogorov-Smirnov, corridas o autocorrelación según la metodología. Superar una prueba no demuestra aleatoriedad absoluta.

8. Distribuciones y transformación

Para una variable uniforme entre a y b:

X = a + (b − a)U
Ejemplo resuelto

Empaque entre 3 y 7 min. U=.25 → X=4 min. U=.80 → X=6.2 min.

9. Variable discreta mediante intervalos

Si demanda 10 tiene probabilidad .20, demanda 20 probabilidad .50 y demanda 30 probabilidad .30, los intervalos acumulados de U permiten seleccionar el resultado. U=.63 → 20; U=.82 → 30.

10. Cadena de generación

Generador → U(0,1) → transformación → variable del sistema → experimento de simulación

✏️ Comprueba antes del laboratorio

1. ¿Número aleatorio y variable aleatoria son lo mismo?

No necesariamente. U puede transformarse para generar una variable del sistema.

2. ¿Qué ocurre al repetir la misma semilla?

Con iguales condiciones se reproduce normalmente la secuencia.

3. X=5+3U y U=.4.

X=6.2.

4. ¿Promedio .5 certifica un generador?

No. Por sí solo no demuestra uniformidad, independencia ni calidad general.

5. Número de fallas y tiempo hasta falla.

Número de fallas: discreta. Tiempo hasta falla: continua.
