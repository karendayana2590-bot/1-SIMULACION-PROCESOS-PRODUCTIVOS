Guía de acompañamiento docente

Simulación de Procesos Productivos · Código 168267 · Unidades 1 y 2

Propósito pedagógico

Esta guía acompaña el aula pública del estudiante. El curso busca que el estudiante conceptualice los componentes de un modelo, planee un proyecto de simulación y avance hacia el diseño de modelos industriales apoyados en herramientas computacionales. Las primeras dos unidades construyen la base conceptual y probabilística necesaria para las unidades posteriores.

Importante: esta página no está enlazada desde el portal estudiantil. Sin embargo, GitHub Pages es público: conserve aquí solo orientaciones docentes que no requieran seguridad real. Para parciales o claves confidenciales use un medio privado institucional.

Unidad 1 · orientación

El estudiante debe poder explicar simulación con sus propias palabras, diferenciar sistema, modelo y simulación; clasificar casos como discretos/continuos, determinísticos/estocásticos y estáticos/dinámicos; argumentar ventajas y limitaciones; comparar simulación con optimización, pronóstico y modelos analíticos; y ordenar las etapas de un estudio.

Preguntas de profundización

¿Qué información de una fábrica incluiría y excluiría de un modelo de capacidad? ¿Cuándo sería costoso experimentar directamente con el sistema real? ¿Un modelo más detallado es necesariamente mejor? ¿Cuál es la diferencia entre verificar y validar? ¿Por qué la simulación no garantiza una decisión óptima?

Laboratorio 1 · resultado base

Preparación: 480/2 = 240 u/día. Moldeado: 480/4 = 120. Acabado: 480/3 = 160. Empaque: 480/5 = 96. Capacidad de línea = 96; cuello de botella = Empaque; demanda = 110; producción posible = 96; demanda no atendida = 14.

Escenario recomendado para discusión: reducir empaque de 5 a 3 min/u aumenta su capacidad a 160; la nueva restricción pasa a Moldeado con 120 u/día. Esto permite mostrar que eliminar un cuello de botella puede revelar otro.

Unidad 2 · orientación

El estudiante debe distinguir número aleatorio de variable aleatoria, comprender el papel de la semilla, reconocer uniformidad, independencia, periodo y reproducibilidad como ideas relevantes, explicar por qué se requieren pruebas estadísticas y comprender conceptualmente la transformación de U(0,1) en variables que representen tiempos, demanda o llegadas.

Preguntas de profundización

¿Por qué un computador genera números llamados pseudoaleatorios? ¿Qué ventaja tiene repetir una secuencia con la misma semilla? ¿Una muestra con promedio cercano a 0.5 demuestra uniformidad? ¿Por qué no basta una inspección visual? ¿Cómo cambia un modelo de producción cuando el tiempo de proceso deja de ser fijo?

Laboratorio 2: el generador congruencial incluido es pedagógico. Su objetivo es visualizar semilla, secuencia y transformación, no certificar un generador profesional.
